### 📊 Resumen del proyecto

Análisis de 624 jugador-temporada de la Premier League (2005/06 → 2025/26)
aplicando la **distribución Binomial** para modelar la efectividad en penaltis.

- **Variable:** k = penaltis convertidos (éxitos)
- **Modelo:** Binomial(n, p̂) con p̂ = 0.8077 (80.8%)
- **Prueba:** Chi-cuadrado de bondad de ajuste (α = 0.05)
- **Resultado:** 3/4 grupos aceptan H₀ → Datos SÍ siguen Binomial
